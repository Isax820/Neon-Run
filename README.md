**NEON RUN** is a fast-paced infinite platformer with glowing cyberpunk visuals. The world gets faster the longer you survive — because the only reward for skill is more pressure.

# 🎮 HOW TO PLAY

Run, jump, and survive. Press [Space] or [Z] to jump — press again mid-air for a double jump. Land on floating platforms, dodge obstacles, and collect coins to boost your score.

# ⚡ FEATURES

- Infinite procedural level generation
- Speed that increases progressively as your score climbs
- Double jump — use it wisely
- 3 types of obstacles: spikes, tall walls, and wide blocks
- Floating platforms to use as shortcuts or safe havens
- Coins to collect for bonus points
- 3 lives with temporary invincibility after taking a hit
- Neon particle effects, parallax star field, and glowing visuals
- Session high score tracking

# 🛠️ HOW TO INSTALL

No installation required. Download the .exe, double-click, and play. Windows only.

Note: Windows SmartScreen may show a warning on first launch — click "More info" then "Run anyway". The file is safe.
